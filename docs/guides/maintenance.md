## Updating the OpenAPI Subset

When the API7 EE OpenAPI spec changes, update `openapi-subset.yaml` and regenerate the client.

**Step 1: Review upstream changes**

```bash
# In the api7ee-3-control-plane repo
git diff openapi/routers/consumer.yaml
git diff openapi/schemas/service.yaml
git diff openapi/schemas/route.yaml
```

**Step 2: Update `openapi-subset.yaml`**

`openapi-subset.yaml` is a manually maintained subset of the full spec. It contains only the 8 paths used by this provider. Sync the relevant request/response schemas.

> The full spec is at `internal/pkg/consts/manifests/openapi.generated.yaml` (generated by `make openapi`).

**Step 3: Regenerate the client**

```bash
make generate
```

**Step 4: Fix compile errors**

```bash
go build ./...
```

Common errors:

| Error | Cause | Fix |
|-------|-------|-----|
| `undefined: client.XxxJSONRequestBody` | Generated type name changed | Search for the new type name and update references |
| `cannot use X as type Y` | Field type changed | Update type conversions in resource files |
| `apiResp.JSON200.Value.XxxField undefined` | Response struct changed | Update `build*ModelFromResponse` functions |

**Step 5: Verify**

```bash
go build ./...
make install
cd examples/provider && terraform plan
```

## Adding a Field to an Existing Resource

Example: adding a `timeout` field to `api7_service`.

**1. Add to Schema** (`internal/provider/service_resource.go`):

```go
"timeout": schema.Int64Attribute{
    Optional:    true,
    Computed:    true,
    Description: "Upstream timeout in seconds.",
},
```

**2. Add to the model struct**:

```go
type ServiceResourceModel struct {
    // ...existing fields...
    Timeout types.Int64 `tfsdk:"timeout"`
}
```

**3. Add to `buildServiceRequestBody`**:

```go
if !m.Timeout.IsNull() && !m.Timeout.IsUnknown() {
    body["timeout"] = m.Timeout.ValueInt64()
}
```

**4. Add to `buildServiceModelFromResponse`**:

```go
if v, ok := m["timeout"].(float64); ok {
    state.Timeout = types.Int64Value(int64(v))
}
```

## Adding a New Resource

Example: `api7_ssl`.

```bash
# 1. Add SSL paths to openapi-subset.yaml
# 2. Regenerate client
make generate

# 3. Create resource file based on an existing one
cp internal/provider/consumer_resource.go internal/provider/ssl_resource.go
# Update type names, fields, and API call methods

# 4. Register in provider.go — add NewSSLResource to the Resources() slice
```
